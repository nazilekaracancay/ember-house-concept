# Ember House Burger

Premium burger restoranları için tasarlanmış, Türkçe ve responsive bir konsept web sitesi.

Bu çalışma Loop Agency tarafından; restoran markalarının dijitalde yalnızca iyi görünmesini değil, iştah uyandırmasını, güven oluşturmasını ve ziyaretçileri rezervasyona yönlendirmesini göstermek amacıyla hazırlanmıştır.

## Canlı Demo

https://ember-house-burger.nzlkrcn.chatgpt.site

## Öne Çıkanlar

- Mobil ve masaüstü uyumlu arayüz
- Premium restoran marka kimliği
- Sinematik ürün ve mekân görselleri
- Menü, marka hikâyesi ve ziyaret bölümleri
- Rezervasyon odaklı çağrılar
- Hareketli duyuru bandı ve mikro etkileşimler
- Türkçe içerik

## Teknolojiler

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- CSS animasyonları

## Yerel Kurulum

```bash
npm install
npm run dev
```

Ardından `http://localhost:3000` adresini açın.

## Proje Yapısı

```text
app/                Web sitesi kaynak kodu
public/images/      Site görselleri
social-media/       Türkçe Instagram kreatifleri
```

## Sosyal Medya

`social-media` klasörü, bu konsept için hazırlanan üç adet 4:5 Instagram gönderisini içerir.

## Not

Ember House hayalî bir markadır. Bu repository, Loop Agency tarafından oluşturulan bir konsept ve portföy çalışmasıdır.
